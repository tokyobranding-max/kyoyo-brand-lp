# 『教養としてのブランド』LP

チカイケ秀夫『教養としてのブランド』の紹介ページです。

- 3Dの本：ドラッグで回転、クリックで開いて試し読み（はじめに〜第1章、32ページ）
- ページの端や角をつかんでめくれます（右綴じ・左から右へ）。めくり音のオン/オフあり
- 23の言葉：暮らしの場面で絞り込み、付箋、読んだ記録（ブラウザに保存）
- 続きは note マガジンで公開中：https://note.com/chikaike/m/m676d481d8327

## 構成

- `index.html` … ページ本体
- `assets/app.js` … 言葉カード・付箋・サイドバーなど
- `assets/book3d.js` … 3Dの本（Three.js r147）
- `assets/pages/` … 試し読みページの画像
- `assets/words/` … 言葉カードの写真（Wikimedia Commons、各カードに撮影者とライセンスを表記）

ビルド不要の静的サイトです。GitHub Pages でそのまま公開できます。
